# Security

Security controls designed to support enterprise deployment include PBKDF2-SHA256 password hashing, JWT access tokens, refresh-session records, session revocation boundary, backend tenant isolation, scoped/expirable API keys, rate-limit middleware, request IDs, CORS configuration, security headers and audit events for sensitive actions.

Production hardening still requires secrets management, TLS, database encryption, managed Redis/PostgreSQL, operational alerting, dependency review, penetration testing and a documented incident-response process.
