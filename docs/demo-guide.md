# Demo guide

## Emergency escalation
1. Sign in as `supervisor@voxrelay.demo`.
2. Open Live Call Console and choose plumbing emergency.
3. Inspect emergency state, escalation route and handoff.
4. Use takeover, create a follow-up and inspect audit history.

## Booking and CRM reliability
1. Sign in as `ops@voxrelay.demo`.
2. Run clinic booking.
3. Inspect entities, booking result and lead.
4. Trigger a local CRM failure, inspect job record, retry and confirm safe success.

## Agent governance
1. Sign in as `agentmanager@voxrelay.demo`.
2. Create a version, run evaluation and submit.
3. Switch to `admin@voxrelay.demo`, approve, activate and inspect audit history.

## Quality loop
1. Sign in as `quality@voxrelay.demo`.
2. Open a review call, inspect entity evidence and add feedback.
3. Create coaching and mark the call as a training candidate.
