# Conversation intelligence

Extracted entities include caller details, service/intent, urgency, location, booking preferences, budget/claim data, consent, language, sentiment proxy and handoff reason. Each evidence record carries value, confidence, source segment IDs, validation state, PII classification, CRM mapping state and reviewer override metadata.

The Entity Evidence panel links a field to transcript evidence, speaker, timestamp, confidence, downstream booking/CRM use and audit history. Local extraction is deterministic and schema-oriented; it is not positioned as a trained production NLU model.
